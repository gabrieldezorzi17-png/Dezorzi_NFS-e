DEZORZI® · EMISSOR DE NFS-e
===========================

PARA INSTALAR
-------------
Dois cliques em "Instalar Dezorzi NFS-e.exe". Ele pergunta duas coisas e faz
o resto:

  ONDE INSTALAR      já vem preenchido com a pasta de aplicativos do seu
                     usuário, que funciona sem pedir administrador. Dá para
                     escolher outra em "Procurar…".
  OS ATALHOS         marque se quer na Área de Trabalho, no menu Iniciar, ou
                     nos dois.

Não precisa instalar Python nem nada. Da segunda vez em diante, abra pelo
atalho — o programa abre em meio segundo. A primeira abertura é a única
demorada, porque é quando ele se instala.

Depois de instalado, o arquivo "Instalar Dezorzi NFS-e.exe" não serve mais
para nada: pode apagar.

PARA REMOVER
------------
Configurações do Windows > Aplicativos > Aplicativos instalados > Dezorzi
NFS-e > Desinstalar. Ele pergunta se as notas emitidas devem sair junto — e
a caixa vem DESMARCADA: nota emitida é documento fiscal, e a prefeitura não
guarda cópia para você.

ATUALIZAÇÕES
------------
Não há o que fazer. Ao abrir, o programa confere se saiu versão nova e, se
saiu, se atualiza sozinho antes de mostrar a tela. As notas emitidas e os
ajustes não são tocados — moram fora da pasta que a atualização troca.

ONDE ELE FICA
-------------
  (a pasta que você escolheu; por padrão %LOCALAPPDATA%\Dezorzi NFS-e\)

      app\              o programa. Esta pasta é TROCADA a cada atualização —
                        não guarde nada aqui dentro.
      config\           modelos de emissão, alíquotas, municípios
      data\             as notas emitidas ficam aqui
      .env              ajustes

Para chegar lá: tecla Windows + R, digite %LOCALAPPDATA% e Enter.

ATENÇÃO: A TRANSMISSÃO ESTÁ ATIVA
---------------------------------
Esta cópia emite de verdade. Ao clicar em emitir, a nota vai para a prefeitura e
passa a existir — nota emitida não se apaga, só se cancela, e nem todo caso
permite cancelamento.

A barra do topo mostra o estado em que o programa está:

    "Transmissão ativa"  (laranja)  -> envia de verdade
    "Modo seguro"        (verde)    -> monta e confere, mas não envia

Para treinar, apresentar ou testar sem risco, vá em Configurações e clique em
"Voltar ao modo seguro". O mesmo botão liga de novo quando quiser.

A SENHA
-------
Não vem junto, de propósito: esta pasta pode ir para um pendrive, e a senha iria
com ela. Digite na tela de entrada; ela fica só na memória enquanto o programa
está aberto.

AS NOTAS
--------
Cada computador tem o histórico dele, na pasta data\. Para levar as notas já
emitidas junto, copie o conteúdo do data\ da máquina de origem. Para várias
máquinas apontarem para o mesmo histórico, use NFSE_HOME no .env.

SE ALGUMA COISA DER ERRADO
--------------------------
O programa mantém um diário do que fez, em data\registro.txt. Ele registra as
emissões, a abertura do layout de impressão, a chegada do PDF e qualquer erro —
sem senha, sem dado sigiloso, para poder ser enviado sem receio.

Se uma nota sair e o PDF não aparecer, é esse arquivo que diz o motivo. Ele
se abre em qualquer editor de texto — para chegar até ele, tecla Windows + R,
%LOCALAPPDATA% e Enter.

SE O WINDOWS RECLAMAR
---------------------
Programa sem assinatura digital costuma levar aviso do SmartScreen na primeira
vez: "Mais informações" > "Executar assim mesmo". Antivírus corporativo pode
barrar — nesse caso, peça para liberar a pasta %LOCALAPPDATA%\Dezorzi NFS-e.
